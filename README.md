#### User Management System ####

## This repo comes with some boilerplate code to get you started with a simple user management system.
## Feel free to refactor it
## Tests need to be written for the API


## This is a simple user management system that allows to do the following tasks with an API:
#  List all users
#  Find and display user id and name
#  Register new users and return a success message and user id
#  Update user name for the given id
#  Delete users

## The above task has to be achieved using the following endpoints:
*** User name is mandatory ***

#  GET /users - returns a list of all users ( with id and name) in the system
#  GET /users/:id - returns a user with the given id[userId can be any format of your choice]
#  POST /users - creates a new user [Users can be duplicated]
#  PUT /users/:id - updates the name of a user with the given id
#  DELETE /users/:id - deletes a user with the given id
